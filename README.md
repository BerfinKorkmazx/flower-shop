# Flower Shop - Responsive Front-End Website

A responsive flower shop website built with HTML5 and CSS3, featuring a clean and modern e-commerce-inspired interface.

This project was developed as part of my front-end learning process. I practiced building a responsive website using semantic HTML, custom CSS, Flexbox, media queries, and Font Awesome icons while customizing the visual design and content around a flower shop concept.

## 🚀 Technologies

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
- Flexbox

## ✨ Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section
- About section
- Product cards with discount labels
- Product hover effects
- Customer review section
- Contact form
- Responsive footer
- Payment method icons
- Smooth scrolling navigation
- Responsive layout for different screen sizes
